# Customer-Satisfaction-Prediction-Brazil-Dataset
KNIME Analytics project focused on descriptive analysis of Brazil survey data using workflow based data processing, visualization, and statistical analysis to uncover demographic patterns, technology awareness trends, consumer behavior, and satisfaction insights.

## Overview

This project presents a descriptive analytics study of survey data collected from respondents in Brazil using KNIME Analytics Platform.

The objective of this project is to explore demographic characteristics, consumer preferences, technology awareness, satisfaction levels, and behavioral trends through workflow-driven analytics.


## Project Objectives

- Perform descriptive analysis on survey datasets
- Analyze demographic distributions
- Study technology awareness patterns
- Examine consumer behavior and satisfaction
- Build automated data analytics workflows using KNIME


## Dataset Analysis Includes

### Demographic Analysis
- Age Distribution
- Gender Distribution
- Income Distribution
- Education Distribution
- Regional Distribution

### Consumer & Behavioral Analysis
- Frequency Distribution
- Online Satisfaction Analysis
- Technology Awareness Analysis

### Technology Awareness Analysis

The project evaluates awareness levels across technologies such as:

- Artificial Intelligence
- Voice Assistants
- Augmented Reality
- Visual Search
- Chatbots
- Personalized Technologies
- Loyalty Programs


## Key Insights

- Younger respondents show higher participation and technology awareness
- Satisfaction levels are generally high but improvement opportunities exist
- Technology awareness varies significantly across demographics
- Regional differences reveal varying adoption patterns
